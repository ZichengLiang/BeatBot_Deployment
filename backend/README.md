# AI Music Composer Backend

This is the backend for the AI Music Composer project. It uses Python 3.10+ and Poetry for dependency management.

## Setup

1. Install dependencies:
```
poetry install
```

2. Activate the virtual environment:
```
poetry shell
```

3. Run the application:
```
poetry run python -m main
```

## Project Structure

- `agents/`: Contains the music composition agent components
- `api/`: Flask API endpoints
- `models/`: Data models and schemas
- `utils/`: Utility functions
